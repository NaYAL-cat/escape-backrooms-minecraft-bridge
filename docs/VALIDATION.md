# 验证范围

开发过程由 Codex 协助。游戏内测试交由使用者完成，发布仓库不声称已经完成真实关卡画面的最终验收。

## V2 已执行的离线检查

- MC 26.3 / Java 25 构建与 80 项实际输入 ABI、短按/长按/释放、换手及原生调用点断言。
- 240 项实际 MC VoxelShape、落地、局部形状和安全点恢复断言。
- 28 项 Python/Lua 协议、坐标、队列、超时、摄像机与碰撞模拟回归。
- 实际 ReShade 6.8.0 parser + D3DCompile：八个 shader 入口，包括三个 compute pass。
- 上传行 pitch/图层偏移对齐、缓冲回收和未完成 fence 保护检查。
- 执行真实 FX 的无窗口 D3D11 WARP 12 个场景与显卡 1920×1200 十个场景：平移、前进、转动、人物轮廓、后室深度遮挡、满屏几何、空帧清理、16:10/16:9 及源分辨率变化。

离屏测试使用独立射线/盒体几何作为参考，不以复刻合成实现作为期望值。最后的 WARP 场景未缺失参考内部像素；显卡场景最坏仍有 122/161388 个参考内部像素未覆盖（约 0.076%）。这些场景未发现深度/颜色配对丢失、分离残影或墙体泄漏。

显卡可见性与世界合成的离屏 GPU 用时，首次约 4.16 ms，后续约 0.26–0.55 ms；不含游戏、帧回读/上传、HUD 和 UE 场景，不代表游戏 FPS。

## 仍需游戏内确认

真实 UE 相机与深度时序、原始输入/Mixin 的实际应用、背包点击/拖动、快速转身时的边缘、复杂场景碰撞、敌人伤害脚本和维度往返。单张源深度图无法重建原视角没有看见的表面。

## 发布副本

公开副本去除了个人路径、安装清单、原始日志、世界原点记录、存档、依赖缓存和构建产物。新增 paths.local.ps1 配置入口，Lua 从已安装脚本的位置推导 IO 目录，构建终端与 ReShade 源码通过环境变量指定。当前游戏安装使用的工作目录与此发布副本分开。


发布副本还执行了：随附 Gradle Wrapper 的完整 Java 构建（320 项断言通过）、可移植原生构建、28 项 Python/Lua 回归、实际 Lua IO 目录/文件往返、所有 PowerShell 脚本解析以及上传布局检查。Universal Modder 对源码副本的秘密/反编译痕迹与后室原始 Content 比对检查通过；实际 Git index 另行逐文件排除了所有构建和运行数据。
